# quiz-master
An app where users can take quizzes for various subjects and admin can manage subjects, quizzes and much more

## Overview
Quiz Master is a multi-user exam preparation platform where:
- **Admins** can manage subjects, chapters, and quizzes.
- **Users** can attempt quizzes and view scores.

## Features
User Authentication (Admin & User)  
Quiz Management (Create, Edit, Delete)  
Chapter & Subject Management 

## Install dependencies and run the app
```bash
pip install -r requirements.txt
python3 app.py
```
